# For Loop  
For loop is generally used when you know **how many times you want to run a loop.**  

## For ( I, C, U)  
I - Init /  -  initialization   

C - Condition  

U - Updation - You can use whichever you want pre or post, (we are using the the variable in the   next) , // i++,++i  

```
for(let i=0; i<10; i++){
console.log(i)
}
``` 

```
for (let i = 0; i < 5; i++) {
    // Click the menu item using index
    console.log(i);
}
// I - Initialize
// C- Condition
// U- Update
```

**Infinite Loop**
```

 for (let j=0; ; j++) {
        console.log(j);
    }
```

**Valid Identifier**
```
for (_1=0 ; _1 <= 10; _1++) {
    console.log(_1);
}
```
